# Fieldnotes

Early previews of focused, privacy-first tools for small businesses. Static site, no build step.

- `src/outputs/` — the site (served at `/`)
  - `index.html` catalog · `voicetask/` `callrecap/` `expenselens/` `fieldaudit/` `paperbrief/` product pages
  - `app/` the workspace preview · `privacy/` data-flow page · `lab/speech-test/` on-device Whisper test bench
- Product pages are generated by `tools/build_pages.py` (edit facts there, then run it).

Privacy rule: no analytics, no server, no claim the code does not back up.
